# Supplementary data — an allele-selective target-site atlas for ATXN1

Five tables. S1–S3 come from the primary analysis (1000 Genomes Phase 3, GRCh37);
S4–S5 from the confirmatory 30× run (1000 Genomes 30× NYGC, GRCh38). All are
restricted to the same 2,504 unrelated samples.

| File | Rows | Contents |
| --- | --- | --- |
| S1 | 85 | Tier-1 candidates, Phase 3: in-gene SpCas9 PAM-altering sites ≥30% heterozygous in all five superpopulations |
| S2 | 24,701 | The complete atlas, Phase 3: every analysed biallelic SNV in *ATXN1* ±200 kb |
| S3 | 26 | Founder-model worst-case eligibility, one row per 1000 Genomes population |
| S4 | 18,819 | The complete atlas, 30× GRCh38, with rsIDs restored |
| S5 | 86 | Tier-1 candidates called on the 30× callset |

## Columns in S1, S2, S4, S5

| Column | Meaning |
| --- | --- |
| `rsid` | dbSNP identifier. In S4/S5 this is restored by exact join to S2 on (pos_grch37, ref, alt); 2,630 rows of S4 keep a `chrom:pos:ref:alt` identifier because Phase 3 did not call them |
| `pos_grch37`, `pos_grch38` | Position in both assemblies. The analysed callset supplies the real value; the other is derived from the gene's constant offset (−231 bp at *ATXN1*), confirmed against dbSNP |
| `ref`, `alt` | Reference and alternative allele, plus strand |
| `region` | `ATXN1_gene` or `flank_200kb` |
| `hetf_ALL`, `hetf_AFR` … `hetf_SAS` | Observed heterozygosity overall and per superpopulation |
| `het_min_superpop` | The lowest of the five superpopulation values — the tier-1 ranking key |
| `<nuclease>_created`, `<nuclease>_destroyed` | Number of PAM sites the alternative allele creates or destroys, for SpCas9 (NGG), SaCas9 (NNGRRT), xCas9_NG (NG) and Cas12a (TTTV), counting both strands |
| `any_pam_alter` | 1 if the variant alters a PAM for any of the four nucleases |

A variant may both create and destroy a PAM, at different offsets or on opposite
strands. The PAM-bearing allele is ALT where the variant creates a PAM and REF where
it destroys one; which direction is usable for a given patient depends on phase.

## Columns in S3

| Column | Meaning |
| --- | --- |
| `pop`, `super` | 1000 Genomes population and superpopulation code |
| `n_hap` | Haplotypes in that population (2 × samples) |
| `worst`, `p1`, `median`, `best` | Eligibility across all candidate founder haplotypes in that population: the minimum, 1st percentile, median and maximum |
| `distinct_profiles` | Distinct PAM profiles across the 468 candidate sites |
| `commonest_profile_n`, `commonest_profile_frac` | Size and share of the commonest profile |

The founder model fixes the disease chromosome to one complete haplotype across all
468 sites and draws the wild-type chromosome from the same population — strictly more
constraining than any real founder effect. `worst` is the adversarial case; the global
floor is 96.46% (LWK).

## Provenance

Every file is regenerated by the analysis package with `python run_all.py`
(`--build phase3` for S1–S3, `--build grch38_30x` for S4–S5, then `annotate_rsids.py`
for the rsID column of S4 and S5). `verify.py` checks the regenerated values against
the figures reported in the manuscript: 41 checks for Phase 3, 39 for the 30× run.
